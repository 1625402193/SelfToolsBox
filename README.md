# 多功能工具箱

一款 Windows 桌面工具集，集成文件分类、批量移动、截图录屏、自动点击、日报周报、定时任务、SVN 批量更新等实用功能。

---

## 📥 安装与启动

- 直接双击运行 `多功能工具箱.exe` 即可使用，无需安装。
- 程序启动后默认置顶显示。
- 提供两个版本：
  - **全能版** — 包含所有功能
  - **工作版** — 专注办公效率，隐藏"文件分类"和"批量移动"功能

---

## 🗂️ 文件分类

将指定文件夹中的文件按照 **日期 + 扩展名** 自动整理到目标文件夹。

### 使用步骤

1. **选择源文件夹** — 点击"浏览"选择要整理的文件夹
2. **选择目标文件夹** — 点击"浏览"选择整理后的存放位置
3. **设置选项**：
   - **操作模式**：复制（保留原文件）或 移动（原文件会被删除）
   - **时间依据**：按文件的创建时间或修改时间分组
   - **包含子文件夹**：是否递归扫描源文件夹的子目录
4. **点击"分析文件"** — 预览分类结果
5. **确认无误后点击"执行复制/移动"**

### 整理后的目录结构

```
目标文件夹/
├── 2024-01-15/
│   ├── jpg/
│   │   ├── photo1.jpg
│   │   └── photo2.jpg
│   ├── pdf/
│   │   └── report.pdf
│   └── docx/
│       └── note.docx
├── 2024-01-16/
│   └── mp4/
│       └── video.mp4
```

## 📁 批量移动

将文件从一个目录批量复制或移动到另一个目录，支持选择性操作。

### 使用步骤

1. **选择源文件夹和目标文件夹**
2. **设置选项**：
   - **操作模式**：复制 或 移动
   - **包含子文件夹**：是否递归扫描子目录
   - **扁平化结构**：开启后忽略原目录层级，所有文件直接放入目标文件夹
3. **点击"扫描文件"** — 显示文件列表
4. **在表格中勾选需要操作的文件**（默认全选）
5. **点击"批量移动/复制"执行操作**

> 💡 表格支持分页浏览（每页 50 条），方便管理大量文件。

## 📸 截图录屏

提供屏幕截图和屏幕录制功能，支持全屏和区域模式，覆盖所有显示器。

### 截图

| 操作 | 说明 |
|------|------|
| **全屏截图** | 一键截取整个屏幕 |
| **选择区域** | 鼠标拖拽框选要截取的区域（支持跨多显示器） |
| **区域截图** | 对已选区域截图 |
| **保存** | 将截图保存为 PNG 到指定目录 |
| **复制到剪贴板** | 直接粘贴使用 |

### 录屏

| 操作 | 说明 |
|------|------|
| **录制帧率** | 可选 1~30 fps |
| **最大时长** | 5 秒 ~ 1 小时，到时自动停止 |
| **选择区域** | 可框选录制区域，不选则全屏录制 |
| **开始录制** | 点击后开始录屏 |
| **停止录制** | 手动停止并保存文件 |

> ⚠️ 录屏格式为 **WebM**，如需 MP4 格式可使用其他工具转码。

### 操作提示

- 选择区域时会弹出全屏半透明遮罩，按住鼠标左键拖拽框选，松开完成
- 按 **ESC** 可取消选区
- 保存目录设置会自动记忆

## 🖱️ 自动点击

按设定的时间间隔在指定屏幕区域内自动执行鼠标点击。

### 使用步骤

1. **选择运行模式**：
   - **持续时间模式** — 运行指定分钟数后自动停止（默认 30 分钟）
   - **时间段模式** — 设定开始和结束时间（如 9:00 ~ 17:00）
2. **设置点击间隔**：
   - **固定间隔** — 每 N 秒点击一次
   - **随机间隔** — 在设定范围内随机选择间隔时间
3. **选择点击区域**：
   - 点击"选择区域"按钮，用鼠标框选一个屏幕区域
   - 每次点击会随机落在该区域内的某个位置
   - 也可以手动输入 X/Y 坐标
4. **点击"开始"按钮运行**

### 运行中状态

- 右侧面板显示点击次数统计
- 日志框实时显示每次点击的坐标和时间
- 每次点击时屏幕上会显示红色波纹动画
- 运行期间自动防止屏幕熄灭

### 停止方式

- 手动点击"停止"按钮
- 到达设定时间后自动停止

## 📝 日报周报

日报录入与周报/月报自动生成工具。

### 日报录入

1. 选择日期（默认为今天）
2. 在文本框中输入工作内容，**每行一项**
3. 点击"保存日报"

> 💡 同一天重复保存会覆盖之前的内容。可点击"加载日报"查看已有记录。

### 周报生成

1. 设置开始和结束日期（点击"本周"可快速设为本周一到周五）
2. 输入周报标题（可选）
3. 点击"生成周报" — 自动从日报中提取该日期范围的内容并编号
4. 可"保存周报"或"复制周报"到剪贴板

### 月报生成

操作同周报，点击"本月"可快速设为当月范围。

### 查看历史

切换到"查看历史"标签，可以查看所有已保存的日报、周报、月报历史记录。

## ⏰ 定时任务

按设定的时间计划自动执行任务，支持软件开关和 SVN 批量更新两大类任务。

### 核心功能

- **定时器总开关**：控制所有定时任务的启停
- **软件开关任务组**：按时间自动启动或关闭指定软件
- **SVN 更新任务组**：按时间自动执行 SVN 批量更新

### 软件开关任务

每个任务可独立配置：

| 配置项 | 说明 |
|--------|------|
| **任务名称** | 自定义名称，方便识别 |
| **程序路径** | 要启动/关闭的 exe 文件路径 |
| **进程名** | 进程名称，用于关闭时匹配（如 `notepad.exe`） |
| **动作** | 启动软件 或 关闭软件 |
| **关闭方式** | 优雅关闭（发送关闭信号）或 强制结束（直接杀进程） |
| **静默模式** | 启动时隐藏窗口 |
| **触发时间** | 可配置多个时间点，每个时间点可选择星期 |

### SVN 更新任务

| 配置项 | 说明 |
|--------|------|
| **任务名称** | 自定义名称 |
| **工程路径** | 一个或多个 SVN 工程目录 |
| **前置 BAT** | SVN 更新前执行的脚本 |
| **后置 BAT** | SVN 更新后执行的脚本 |
| **触发时间** | 组级统一配置，所有 SVN 任务共享 |

### 触发时间设置

- 每个触发时间由 **时:分** + **星期选择** 组成
- 支持添加多个触发时间（如：9:00 周一到周五、18:00 周一到周五）
- 星期可多选，0=周日，1-6=周一到周六

### 使用注意

- 定时任务依赖程序持续运行，关闭程序后定时器停止
- 开启定时器后，程序会自动防止系统休眠
- 任务执行日志实时显示在界面底部
- 配置修改后自动保存，重启后恢复

## 🔄 SVN 批量更新

多任务片并行的 SVN 批量更新工具，支持前置/后置 BAT 脚本和定时触发。

### 核心概念

- **任务片**：一组关联的操作集合，包含工程路径 + 前置BAT + SVN Update + 后置BAT
- **并行执行**：多个任务片之间并行运行，互不等待
- **分阶段执行**：当有任何任务片配置了前置BAT时，自动分为两阶段执行

### 使用步骤

1. **添加任务片** — 点击"添加任务片"创建新的任务配置
2. **配置任务片**：
   - **任务名称**：自定义名称，方便识别
   - **工程路径**：添加一个或多个 SVN 工程目录
   - **前置BAT**（可选）：SVN Update 前执行的脚本（如关闭 Unity）
   - **执行 SVN Update**：是否执行 SVN 更新
   - **后置BAT**（可选）：SVN Update 后执行的脚本（如启动 Unity）
3. **开关控制**：每个操作（前置BAT / SVN / 后置BAT）都可单独启用或禁用
4. **点击"执行全部"** — 弹出确认窗口，展示完整执行计划
5. **确认后执行**

### 执行策略

| 场景 | 执行方式 |
|------|----------|
| **有前置BAT** | 阶段一：并行执行所有前置BAT → 等全部完成 → 阶段二：并行执行 SVN + 后置BAT |
| **无前置BAT** | 所有任务片全部并行执行 |

### 定时触发

- 启用定时开关，设置执行时间（精确到分钟）
- 选择每周执行日（默认周一到周五）
- 定时触发时自动执行，跳过确认弹窗
- 配置自动保存，重启后保留

### TortoiseSVN 窗口

- SVN Update 使用 TortoiseSVN 图形界面执行
- 更新窗口**不会自动关闭**，你可以查看冲突详情
- 手动关闭 TortoiseSVN 窗口后，流程才会继续
- 进度条会显示"等待TortoiseSVN窗口关闭"提示

### 进度与日志

- **总进度条**：显示整体完成百分比
- **任务片进度**：每个任务片独立显示当前步骤和进度
- **执行日志**：实时输出每一步操作的结果（成功/失败/冲突）
- 支持运行中"中止"操作

## ❓ 常见问题

**Q: 程序窗口总是在最前面怎么办？**
A: 这是默认设计，方便随时使用。暂不支持取消置顶。

**Q: 录屏保存的文件用什么播放器打开？**
A: WebM 格式可以用浏览器（Chrome/Edge）或 VLC 播放器打开。

**Q: 自动点击时为什么会看到红色圆圈？**
A: 这是点击位置的视觉反馈，方便确认点击位置是否正确。

**Q: 文件分类后原文件还在吗？**
A: 取决于你选择的模式 — 复制模式保留原文件，移动模式会删除原文件。

**Q: SVN 更新时界面显示"卡住"是怎么回事？**
A: 这是正常现象。SVN Update 窗口不会自动关闭，需要你查看结果后手动关闭，关闭后流程自动继续。进度条会提示"等待TortoiseSVN窗口关闭"。

**Q: 定时任务需要程序一直开着吗？**
A: 是的，定时触发依赖程序运行中的定时器，关闭程序后定时任务不会执行。

**Q: 前置BAT执行失败会影响后续操作吗？**
A: 不会。即使前置BAT报错，阶段二（SVN + 后置BAT）仍然会继续执行，错误信息会在日志中显示。

**Q: 全能版和工作版有什么区别？**
A: 工作版隐藏了"文件分类"和"批量移动"两个功能，专注于办公效率工具。其他功能完全一致。
