## 🗂️ 文件分类

将指定文件夹中的文件按照 **日期 + 扩展名** 自动整理到目标文件夹。

### 使用步骤

1. **选择源文件夹** — 点击"浏览"选择要整理的文件夹
2. **选择目标文件夹** — 点击"浏览"选择整理后的存放位置
3. **设置选项**：
   - **操作模式**：复制（保留原文件）或 移动（原文件会被删除）
   - **时间依据**：按文件的创建时间或修改时间分组
   - **包含子文件夹**：是否递归扫描源文件夹的子目录
4. **点击"分析文件"** — 预览分类结果
5. **确认无误后点击"执行复制/移动"**

### 整理后的目录结构

```
目标文件夹/
├── 2024-01-15/
│   ├── jpg/
│   │   ├── photo1.jpg
│   │   └── photo2.jpg
│   ├── pdf/
│   │   └── report.pdf
│   └── docx/
│       └── note.docx
├── 2024-01-16/
│   └── mp4/
│       └── video.mp4
```

## 📁 批量移动

将文件从一个目录批量复制或移动到另一个目录，支持选择性操作。

## 🖼️ 批量复制图片

按图片命名规则，把源路径下的图片自动分发到目标路径中已有的对应目录，适用于美术资源批量回填的场景。

### 使用步骤

1. **添加源路径和目标路径**（各支持任意多个）。首个源路径会用于存放工具生成的辅助文件夹。
2. **重建目标索引** — 为**每个目标路径分别**建立四套查询表：同名、各级前缀、后缀词、尺寸。索引保存在软件本地目录，首次使用时自动创建，可随时手动重建。
3. **点击「开始执行」** — 依次完成：
   - 重建索引（若开启「执行前自动重建索引」）
   - 扫描源路径：同名文件合并（只保留创建/修改时间最新的一张）+ 尺寸校验
   - 对每张图逐级匹配并复制到各目标路径

### 多目标路径是完全独立的

每个目标路径都是独立的处理单元，检索、索引、匹配、复制全程互不重叠。同一张源图会**分别**复制到每个目标路径下各自对应的目录：

```
Icon_ShareTalk_Btn.png
  ├→ D:\ProjA\UI\Share\      （按 ProjA 的索引匹配）
  └→ D:\ProjB\Res\Talk\      （按 ProjB 的索引匹配）
```

某个目标路径命中或未命中，都不影响其他目标路径。多目录选择、冲突确认、结果统计也均按目标路径分别进行。

### 尺寸校验

工具会检查图片宽高是否均为 **2 的倍数**，但**不会强制剔除**不合格的图片 —— 是否复制到目标路径由你决定。可在「选项 → 尺寸非 2 的倍数时」选择处理方式：

| 选项 | 行为 |
|------|------|
| **逐张询问**（默认） | 执行时弹窗列出所有不合格图片，逐张勾选是否复制（默认全不勾选） |
| **全部复制** | 不询问，全部照常复制 |
| **全部不复制** | 不询问，全部跳过 |

另有「尺寸异常图另存备查」开关（默认开启）：把这些图片额外复制一份到 `源路径1/尺寸异常/`，便于集中查看或修图。该动作与是否复制到目标路径**互不影响**，文件夹仅在确有此类图片时才创建，界面会出现「打开尺寸异常文件夹」按钮。

> 💡 扫描完成后，工具栏会出现「查看尺寸异常图」按钮，可随时查看清单。分类结果表格中这些图片的尺寸会标橙色并注明「非2倍数」。

### 匹配与复制规则

对**每一张**源图，在**每个目标路径内部**独立按优先级逐级匹配，命中即停：

| 优先级 | 规则 | 说明 |
|--------|------|------|
| 1️⃣ | **同名精确匹配** | 目标中已存在同名文件 → 直接定位到该文件所在目录（替换场景） |
| 2️⃣ | **后缀词匹配** | 文件名以后缀词结尾时（默认 `Fang` / `Yuan`），定位到「同前缀且同后缀」的资源所在目录，避免 Fang 与 Yuan 混淆 |
| 3️⃣ | **前缀逐级回退** | 按 `_` 分段，从最长前缀逐级缩短，命中第一个存在已有资源的前缀（最精确的那一级） |
| 4️⃣ | **尺寸兜底** | 以上都没命中时，按「宽×高」索引兜底。读不出尺寸的图不参与 |
| 5️⃣ | 全都没命中 | 复制到 `源路径1/未匹配/` |

四条规则都可单独开关。

#### 后缀词匹配示例

`Icon_RewardHeader_ChangE_BiaoQing_Fang.png` 去掉后缀词后逐级缩短前缀，命中目标中的
`Icon_RewardHeader_ChangE_Fang.png`（同前缀 + 同 `_Fang` 后缀），从而定位到 `Fang` 子目录。

### 多候选目录的消歧

任一级规则命中**多个**候选目录时：

1. **先用源图分辨率消歧** —— 只保留含有同分辨率资源的候选目录，唯一则自动采用
2. 仍有多个时，若开启「多目录时按数量自动决定」，取命中数量最多的目录
3. 还是无法确定 → 弹窗让你选择（选项中会标注各候选目录已有资源的分辨率，便于判断）

> 💡 头像类资源常按分辨率区分目录，例如 `Hero\TouXiang` 192×192、`Hero\TouXiangKa` 124×168、`Hero\TouXiangLOD2` 48×48，分辨率消歧对这类场景很有效。

### 同名文件的处理

| 情况 | 处理方式 |
|------|----------|
| 内容完全相同（大小 + MD5 一致） | **自动跳过**，不复制也不询问（可通过「内容相同自动跳过」关闭） |
| 内容不同 | 弹窗逐项确认覆盖/跳过（支持一键全部覆盖或全部跳过） |

> 💡 存在多个目标路径时，未匹配文件夹会再按目标路径分子目录，如 `源路径1/未匹配/ProjA/`。
>
> 💡 「覆盖前询问」开关可关闭覆盖弹窗，关闭后遇到内容不同的同名文件直接覆盖。

### 操作记录

全流程所有操作都会记录并在界面底部按级别着色显示（成功 / 警告 / 错误），同时持久化到本地日志文件。执行结果先按目标路径分别汇总，再给出总计。支持按级别筛选、导出为文本、一键清空。

### 数据存储与隐私

本功能产生的索引、操作日志、路径配置**只保存在本机的系统用户目录**，位于项目仓库之外，不会随项目上传：

```
%APPDATA%\file-classifier-tools\
  ├── image-copy-index\*.json          统计与目录分布（每个目标路径一个文件）
  ├── image-copy-index\*.lookup.json   同名/前缀/后缀词查询表
  ├── image-copy-index\*.size.json     尺寸索引
  ├── image-copy-log.jsonl             操作日志
  └── app-config.json                  源/目标路径等配置
```

> ⚠️ 这些文件含有完整的本地磁盘路径与项目目录结构。导出日志时会有提示，请勿上传到公开仓库或分享给他人。界面「目标索引明细」底部可直接点击打开该目录查看。

> 💡 所有路径与开关设置会自动保存，下次打开软件无需重新配置。

## ⭐ 媒体评分

浏览一个文件夹里的图片/视频，逐张打星评分，再按星级批量导出或删除。适合摄影选片、素材筛选等场景。

### 使用步骤

1. 选择源文件夹（含图片/视频的目录），点击「扫描」——这一步只快速探测文件夹下有哪些扩展名、各多少个文件，不会真正加载。
2. 在「预览类型」中勾选要预览的文件类型（默认全选），点击「开始预览」才会真正加载这些文件用于浏览打分。**未勾选的类型完全不参与预览**（不扫描、不渲染、不生成缩略图），这一步专门用来在大文件夹场景下排除重型类型（如 RAW），避免卡顿甚至崩溃。
3. 用左侧列表或键盘 `←` / `→` 切换文件，`1`~`5` 打分、`0` / `Delete` 清除评分，评分自动保存到源文件夹下的 `.media-ratings.json`。
4. 评分完成后，在「按评分导出/分类」或「按评分删除」中勾选星级，执行导出或删除。

### 同名不同类型文件

如果同一文件夹下有同名但类型不同的文件（例如 `5099.jpg` 与 `5099.arw`，常见于 RAW+JPG 双存的相机），即使 `.arw` 没有被选入预览、也没有被评分，导出或删除已评分的 `.jpg` 时依然会检测到它，并弹窗询问：

- **仅导出/删除预览类型**：保持原有行为，只处理已评分/已选中类型的文件。
- **两种类型都导出/删除**：导出时会在目标文件夹下按类型（`JPG` / `ARW` 等）分别创建子文件夹存放；删除时两种类型一起移入回收站。

### 按评分删除

评分完成后可直接在界面里勾选一个或多个星级（含未评分），一键将匹配的文件移到回收站（可从回收站恢复），无需切到文件管理器手动挑选删除。同样支持上述"同名不同类型文件"的询问。

## 🖱️ 自动点击

按设定的时间间隔在指定屏幕区域内自动执行鼠标点击。

### 使用步骤

1. **选择运行模式**：
   - **持续时间模式** — 运行指定分钟数后自动停止（默认 30 分钟）
   - **时间段模式** — 设定开始和结束时间（如 9:00 ~ 17:00）
2. **设置点击间隔**：
   - **固定间隔** — 每 N 秒点击一次
   - **随机间隔** — 在设定范围内随机选择间隔时间
3. **选择点击区域**：
   - 点击"选择区域"按钮，用鼠标框选一个屏幕区域
   - 每次点击会随机落在该区域内的某个位置
   - 也可以手动输入 X/Y 坐标
4. **点击"开始"按钮运行**

### 运行中状态

- 右侧面板显示点击次数统计
- 日志框实时显示每次点击的坐标和时间
- 每次点击时屏幕上会显示红色波纹动画
- 运行期间自动防止屏幕熄灭

### 停止方式

- 手动点击"停止"按钮
- 到达设定时间后自动停止

## ⏰ 定时任务

按设定的时间计划自动执行任务，支持软件开关和 SVN 批量更新两大类任务。

### 核心功能

- **定时器总开关**：控制所有定时任务的启停
- **软件开关任务组**：按时间自动启动或关闭指定软件
- **SVN 更新任务组**：按时间自动执行 SVN 批量更新

### 软件开关任务

每个任务可独立配置：

| 配置项 | 说明 |
|--------|------|
| **任务名称** | 自定义名称，方便识别 |
| **程序路径** | 要启动/关闭的 exe 文件路径 |
| **进程名** | 进程名称，用于关闭时匹配（如 `notepad.exe`） |
| **动作** | 启动软件 或 关闭软件 |
| **关闭方式** | 优雅关闭（发送关闭信号）或 强制结束（直接杀进程） |
| **静默模式** | 启动时隐藏窗口 |
| **触发时间** | 可配置多个时间点，每个时间点可选择星期 |

### SVN 更新任务

| 配置项 | 说明 |
|--------|------|
| **任务名称** | 自定义名称 |
| **工程路径** | 一个或多个 SVN 工程目录 |
| **前置 BAT** | SVN 更新前执行的脚本 |
| **后置 BAT** | SVN 更新后执行的脚本 |
| **触发时间** | 组级统一配置，所有 SVN 任务共享 |

### 触发时间设置

- 每个触发时间由 **时:分** + **星期选择** 组成
- 支持添加多个触发时间（如：9:00 周一到周五、18:00 周一到周五）
- 星期可多选，0=周日，1-6=周一到周六

### 使用注意

- 定时任务依赖程序持续运行，关闭程序后定时器停止
- 开启定时器后，程序会自动防止系统休眠
- 任务执行日志实时显示在界面底部
- 配置修改后自动保存，重启后恢复

## 🔄 SVN 批量更新

多任务片并行的 SVN 批量更新工具，支持前置/后置 BAT 脚本和定时触发。

### 核心概念

- **任务片**：一组关联的操作集合，包含工程路径 + 前置BAT + SVN Update + 后置BAT
- **并行执行**：多个任务片之间并行运行，互不等待
- **分阶段执行**：当有任何任务片配置了前置BAT时，自动分为两阶段执行

### 使用步骤

1. **添加任务片** — 点击"添加任务片"创建新的任务配置
2. **配置任务片**：
   - **任务名称**：自定义名称，方便识别
   - **工程路径**：添加一个或多个 SVN 工程目录
   - **前置BAT**（可选）：SVN Update 前执行的脚本（如关闭 Unity）
   - **执行 SVN Update**：是否执行 SVN 更新
   - **后置BAT**（可选）：SVN Update 后执行的脚本（如启动 Unity）
3. **开关控制**：每个操作（前置BAT / SVN / 后置BAT）都可单独启用或禁用
4. **点击"执行全部"** — 弹出确认窗口，展示完整执行计划
5. **确认后执行**

### 执行策略

| 场景 | 执行方式 |
|------|----------|
| **有前置BAT** | 阶段一：并行执行所有前置BAT → 等全部完成 → 阶段二：并行执行 SVN + 后置BAT |
| **无前置BAT** | 所有任务片全部并行执行 |

### 定时触发

- 启用定时开关，设置执行时间（精确到分钟）
- 选择每周执行日（默认周一到周五）
- 定时触发时自动执行，跳过确认弹窗
- 配置自动保存，重启后保留

### TortoiseSVN 窗口

- SVN Update 使用 TortoiseSVN 图形界面执行
- 更新窗口**不会自动关闭**，你可以查看冲突详情
- 手动关闭 TortoiseSVN 窗口后，流程才会继续
- 进度条会显示"等待TortoiseSVN窗口关闭"提示

### 进度与日志

- **总进度条**：显示整体完成百分比
- **任务片进度**：每个任务片独立显示当前步骤和进度
- **执行日志**：实时输出每一步操作的结果（成功/失败/冲突）
- 支持运行中"中止"操作

## ❓ 常见问题

**Q: 程序窗口总是在最前面怎么办？**
A: 这是默认设计，方便随时使用。可在左侧栏底部或菜单栏「窗口 → 窗口置顶」关闭；关闭后窗口不再置顶。

**Q: 录屏保存的文件用什么播放器打开？**
A: WebM 格式可以用浏览器（Chrome/Edge）或 VLC 播放器打开。

**Q: 自动点击时为什么会看到红色圆圈？**
A: 这是点击位置的视觉反馈，方便确认点击位置是否正确。

**Q: 文件分类后原文件还在吗？**
A: 取决于你选择的模式 — 复制模式保留原文件，移动模式会删除原文件。

**Q: SVN 更新时界面显示"卡住"是怎么回事？**
A: 这是正常现象。SVN Update 窗口不会自动关闭，需要你查看结果后手动关闭，关闭后流程自动继续。进度条会提示"等待TortoiseSVN窗口关闭"。

**Q: 定时任务需要程序一直开着吗？**
A: 是的，定时触发依赖程序运行中的定时器，关闭程序后定时任务不会执行。

**Q: 前置BAT执行失败会影响后续操作吗？**
A: 不会。即使前置BAT报错，阶段二（SVN + 后置BAT）仍然会继续执行，错误信息会在日志中显示。

**Q: 全能版和工作版有什么区别？**
A: 工作版隐藏了"文件分类"和"批量移动"两个功能，专注于办公效率工具。其他功能完全一致。
